# jixun-2

2026 年杭州电子科技大学电子设计竞赛 B 题“物体智能识别瞄准装置”的当前工程版本。

## 项目概括

本项目由 STM32F407 大疆 C 板和 MaixCam2 两部分组成：

- STM32F407：负责 BMI088 姿态解算、双轴云台稳定、CAN 电机控制、激光控制、视觉串口接收和视觉闭环修正。
- MaixCam2：负责 YOLO 目标检测、触控选靶、目标跟踪、屏幕显示，并通过 UART 向 STM32 发送目标相对瞄准点的像素误差。

当前工程已经具备基础闭环能力：MaixCam2 识别并锁定目标后，输出 dx/dy 给 STM32；STM32 在 `VISION_STAB` 模式下把像素误差转换为云台角度修正，使激光点向目标中心收敛。

## 目录说明

- `Application/`：FreeRTOS 应用任务，包括 INS 姿态任务、云台任务和算法模块。
- `Mode/`：云台工作模式，包括稳定、角度测试、重力校准、视觉稳定等。
- `Device/`：BMI088、视觉串口、激光、蓝牙等设备抽象。
- `bsp/`：CAN、SPI、UART、Laser、Delay 等板级驱动。
- `Inc/`、`Src/`：CubeMX/HAL 生成代码、全局配置和外设初始化。
- `MDK-ARM/`：Keil 工程文件。
- `vision/`：MaixCam2 端运行代码、YOLO 模型、串口通信和目标跟踪逻辑。
- `tools/`：YOLO 数据集生成、筛选、评估、训练和转换辅助脚本。
- `*.md`：题目理解、硬件引脚、实现路线和项目逻辑说明文档。

## 当前状态

- STM32 端已接入 BMI088、CAN 电机、激光 GPIO 和 MaixCam2 UART 数据。
- MaixCam2 端已支持 YOLO 检测、触控选靶、卡尔曼中心跟踪、目标丢失/重捕获和串口输出。
- 视觉闭环已加入限幅、死区、小积分和积分泄放，用于减少稳态误差并抑制过冲。
- UI 中白色十字表示瞄准参考点，蓝色十字表示当前目标中心，目标是让二者重合。

## 未完成任务

- 继续实测调参：视觉闭环的 `KP/KI`、限幅、积分泄放和极性仍需按实物响应微调。
- 完成长期稳定性验证：遮挡、目标快速移动、重复目标、弱光和激光反光场景还需要测试。
- 整理 Maix 视觉代码：`vision/app_legacy.py` 仍是主逻辑文件，后续应逐步拆分到 `detectors/`、`trackers/`、`comm/`、`ui/` 等模块。
- 完善通信鲁棒性：当前 UART 状态回传偶发粘包/坏包，需要进一步增强帧同步和校验。
- 固化标定流程：瞄准点、Pitch 重力补偿、云台零点和视觉中心偏移需要形成稳定的现场标定步骤。
- 补充最终部署文档：包括 STM32 编译下载、MaixCam2 部署、接线说明、启动顺序和故障排查。
